    📚 Python Scientific Computing & Data Analysis Libraries

    Library / Module Purpose Most Common Functions / Methods
    pandas High-level data manipulation and analysis with DataFrame and Series objects. pd.read_csv(), pd.read_excel(), DataFrame.head(), DataFrame.info(), DataFrame.describe(), DataFrame.groupby(), DataFrame.merge(), DataFrame.concat(), DataFrame.plot()
    matplotlib Core plotting library for static, animated, and interactive visualisations. Usually accessed via pyplot. — (backend for pyplot)
    matplotlib.pyplot State-based interface for creating plots (MATLAB-like). plt.plot(), plt.scatter(), plt.bar(), plt.hist(), plt.xlabel(), plt.ylabel(), plt.title(), plt.legend(), plt.grid(), plt.show()
    scipy Scientific computing: optimisation, integration, interpolation, statistics, and more. — (parent library for specialised submodules)
    scipy.fft Fast Fourier Transform utilities for signal processing and frequency analysis. fft(), ifft(), fftfreq(), rfft(), irfft()
    scipy.optimize Numerical optimisation, curve fitting, and root finding. minimize(), curve_fit(), root(), fsolve()
    random Pseudorandom number generation and random operations on sequences. random(), randint(), choice(), shuffle(), seed()
    pathlib Object-oriented filesystem path handling. Path(), Path.exists(), Path.is_file(), Path.is_dir(), Path.iterdir(), Path.glob(), Path.read_text(), Path.write_text()
    numpy Core numerical computing: n-dimensional arrays, vectorised operations, linear algebra. np.array(), np.zeros(), np.ones(), np.linspace(), np.mean(), np.std(), np.sum(), np.dot(), np.reshape(), np.transpose(), np.concatenate(), np.linalg.inv(), np.linalg.eig()
