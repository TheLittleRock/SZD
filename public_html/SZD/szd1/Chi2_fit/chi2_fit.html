    Chi2 Fit - Least Squares Method

    The least squares method arises naturally as a special case of the maximum likelihood method (MLM) when the measurement errors are assumed to be independent Gaussian random variables. In this situation, maximizing the likelihood is exactly equivalent to minimizing the familiar chi‑square function used in least‑squares fitting.

    Assumptions

    We assume that each measured data point \(y_i\) is drawn from a normal distribution with:

    • mean being the unknown parameter \(f(x_i;\theta)\)
    • standard deviation is known (measurement uncertainty) \(\sigma_i\)

    Thus:

    \[y_i \sim \mathcal{N}\!\left(f(x_i;\theta),\, \sigma_i^2\right)\]

    Step 1: Write the Gaussian probability density

    For a single measurement \(y_i\):

    \[ p(y_i \mid \theta) = \frac{1}{\sqrt{2\pi}\,\sigma_i} \exp\!\left[ -\,\frac{(y_i - f(x_i;\theta))^2}{2\sigma_i^2} \right]. \]

    Step 2: Construct the likelihood (product of independent Gaussians)

    Assuming all measurements are independent, the likelihood \( \mathcal{L}(\theta) \) is:

    \[ \mathcal{L}(\theta) = \prod_{i=1}^{N} \frac{1}{\sqrt{2\pi}\,\sigma_i} \exp\!\left[ -\,\frac{(y_i - f(x_i;\theta))^2}{2\sigma_i^2} \right]. \]

    Step 3: Take the logarithm of the likelihood

    Taking the ln:

    \[ \ln \mathcal{L}(\theta) = - \sum_{i=1}^{N} \left[ \ln(\sqrt{2\pi}\sigma_i) + \frac{(y_i - f(x_i;\theta))^2}{2\sigma_i^2} \right]. \]

    The first term, \(\ln(\sqrt{2\pi}\sigma_i)\), is independent of the parameters \(\theta\), so it can be dropped.

    Step 4: Keep only the parameter‑dependent part

    \[ \ln \mathcal{L}(\theta) \;\propto\; - \frac{1}{2} \sum_{i=1}^{N} \frac{(y_i - f(x_i;\theta))^2}{\sigma_i^2}. \]

    Step 5: Maximizing the log‑likelihood is equivalent to minimizing \(\chi^2\)

    Define the chi‑square:

    \[ \chi^2(\theta) = \sum_{i=1}^{N} \left(\frac{y_i - f(x_i;\theta)}{\sigma_i}\right)^2. \]

    Thus:

    \[ \theta_{\text{ML}} = \arg\max_\theta \ln \mathcal{L}(\theta) = \arg\min_\theta \chi^2(\theta). \]

    Poisson-like errors

    In some cases (e.g. \(\sigma_i\) are not known), one can use an approximation motivated by a Poissonian distribution (for event counts): \(\sigma_i \approx \sqrt{y_i}\).

    This choice is ok for well-populated bins (\(y_i > 12\)), i.e. Normally behaved bins.

    There is also a possible (unusual) choice \(\sigma_i \approx \sqrt{f(x_i)}\) (i.e. from the predicted function). This is called Pearson's \(\chi^2\) fit.

    Now let's check if we do the same as standard tools:

    in ROOT the usual function to fit histogram is used: 

    hist->Fit(f1);
    where the default choice is \(\chi^2\). It can be directly demanded by additional option: 
    hist->Fit(f1, "CHI2");
    unlike python's curve_fit, this function can be switched to Poisson likelihood MLM fit: (for event counts) 
    h->Fit(f1, "L");
    and for weighted events (Bincintents are not natural numbers) 
    h->Fit(f1, "WL");

    scipy.optimize.curve_fit always performs a least‑squares minimization 

    popt, pcov = curve_fit(model, x_dummy, x_position, sigma=x_error, absolute_sigma=True)
    An option: absolute_sigma=True secures that SciPy returns the \(\chi^2\) as we expect it, otherwise SciPy rescales the covariance matrix and the resulting output is \(\chi^2\)/NDF (i.e. rescaled by the number of degrees of freedom). The default choice is absolute_sigma=False

    import numpy as np
from scipy.optimize import curve_fit

# -------------------------
# Input data
# -------------------------
x_position = np.array([0.42, 0.38, 0.32, 0.33])
x_error    = np.array([0.06, 0.08, 0.07, 0.05])

# Fit parameter scanning range (same as ROOT example)
grid_x_size = 100
c_values = np.linspace(0.32, 0.42, grid_x_size + 1)

# -------------------------
# (1) Manual chi2 scan
# -------------------------
def chi2_value(c):
    return np.sum(((x_position - c) ** 2) / (x_error ** 2))

chi2_list = np.array([chi2_value(c) for c in c_values])

i = np.argmin(chi2_list)
min_chi2 = chi2_list[i]
best_c = c_values[i]

print("Manual fit:")
print(f"  best c = {best_c:.6f}")
print(f"  chi2   = {min_chi2:.6f}")
print()

# -------------------------
# (2) SciPy fit equivalent to ROOT TF1("[0]")
# -------------------------

# constant function for fitting
def model(x, c):
    return c

# Fake x-bin centers (ROOT would ignore x values in constant fit)
x_dummy = np.arange(len(x_position))

# Use sigma = errors → χ² fit like ROOT
popt, pcov = curve_fit(model, x_dummy, x_position, sigma=x_error, absolute_sigma=True)

c_fit = popt[0]

# Compute chi2 from the fit result
residuals = (x_position - model(x_dummy, c_fit)) / x_error
chi2_fit = np.sum(residuals ** 2)
ndf = len(x_position) - 1

print("SciPy fit (ROOT-like):")
print(f"  fitted c = {c_fit:.6f}")
print(f"  chi2     = {chi2_fit:.6f}")
print(f"  NDF      = {ndf}")
print()

# -------------------------
# Compare results
# -------------------------
print("Comparison:")
print(f"  SciPy fit:  {c_fit:.6f}")
print(f"  Manual:     {best_c:.6f}")
print(f"  Δ = {abs(c_fit - best_c):.6e}")

{

    Double_t nbins=100;

    //signal
    TF1* fce1=new TF1("fce1","[0]*exp(-(x-[1])*(x-[1])/(2*[2]*[2]))",0,200);
    fce1->SetParameter(0,1); //A
    fce1->SetParameter(1,mu); //mu
    fce1->SetParameter(2,sigma); //sigma

    //background
    TF1* fce2=new TF1("fce2","[0]*x+[1]",0,200);

    TCanvas *c1 = new TCanvas("c1","signal+background",10,10,900,600);
    TH1D *hsb=new TH1D("hsb","hsb",nbins,0,200);

    //generate signal + background sample (e.g. invariant mass of unlike-sign pairs of kaons and pions)
    for(int n=0; n<N_signal;n++)
    {
        //first generate the signal...
        double rnd=fce1->GetRandom();
        hsb->Fill(rnd);
    } 
    for(int n=0; n<N_bg;n++)
    {
        //...and then generate the background
        double rnd=fce2->GetRandom();
        hsb->Fill(rnd);
    }
    hsb->SetTitle("signal+background (ULS)");
    hsb->Draw();

    //generate pure background sample (eg. using like-sign sample)
    for(int n=0; n<N_bg;n++)
    {
        double rnd=fce2->GetRandom();
        hbg->Fill(rnd);
    }
    hbg->SetTitle("background (LS)");
    hbg->Draw();

    //remove negative values

            float val=hsg->GetBinContent(bn);
            if(val<0)hsg->SetBinContent(bn,0);
        }
    }
    hsg->SetTitle("signal after BG subtraction");
    hsg->Draw("e");

}


float lhood(TH1D* hdata, float a, float b, TF1* f1)
{
    f1->SetParameter(0,a);
    f1->SetParameter(1,b);
    float logLhood=0;
    int npoints=hdata->GetNbinsX();
    for(int i=1; i<=npoints; i++) //loop over histogram bins
    {
        //read x data and their counts from histogram
        float x=hdata->GetBinCenter(i);
        int n=hdata->GetBinContent(i);
        float width=hdata->GetBinWidth(i);
        float prob=(f1->Eval(x)); 

        logLhood+=n*TMath::Log(prob);
    }
    return logLhood;
}

//gaussian distribution
double Fgaussian(double* x, double* par)
{
    double pi=TMath::Pi();
    double denom=TMath::Sqrt(2*pi*par[1]*par[1]);

    double y;
    if(par[1]>0)
    {
        float frac=((x[0]-par[0])/par[1]);
        y=(par[2]/denom)*TMath::Exp(-0.5*frac*frac);
    }
    else y=0;
    return y;
}
