    RooFit - WW fraction

    RooFit is a powerful statistical modeling and fitting framework integrated into ROOT, designed for probability density function (PDF) modeling, data fitting, and likelihood analysis. It allows users to construct complex models using a modular, object-oriented approach. RooFit supports binned and unbinned likelihood fits, making it ideal for high-energy physics (HEP) analyses. It seamlessly integrates with RooStats for statistical hypothesis testing and confidence intervals. The framework also provides visualization tools, allowing users to overlay fits and generate publication-quality plots. Its flexibility, combined with Python and C++ support, makes RooFit a standard tool in the HEP community.

    Homework

    Physics task is to measure a product of pseudo-rapidities of two muons in proton-proton collisions. In the code, the variable is called etaeta:

    RooRealVar etaeta("etaeta", "etaeta", -6., 6.);

    From Monte-Carlo generators we have distributions how this variable looks like for 3 production mechanisms:
    1) WW production
    2) WZ production
    3) top anti-top production

    We consider WW production as signal, the others are background. For signal, we have 2 options: Sdata (signal-like data) or Smodel (signal-like Monte-Carlo model):

    TFile fin1("data_WWsignal_data.root");
TH1D* h_Sdata = (TH1D*)fin1.Get("LepPair_etaprod");
TFile fin11("data_WWsignal_model.root");
TH1D* h_Smodel = (TH1D*)fin11.Get("LepPair_etaprod");

    The goal is to fit Smodel to pseudo-data generated using Sdata. WHY? We need a distribution of the result, not just a single result - to get the proper statistical uncertainty. Therefore we make a loop for e.g. 10000 repeats:
