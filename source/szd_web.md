# Web předmětu SZD (Archiv)

Tato sekce obsahuje lokální kopii oficiálního webu předmětu **SZD (Statistické zpracování dat)** z katedry fyziky FJFI ČVUT vyučovaného Dr. Miroslavem Myškou (původně dostupného na `https://kf.fjfi.cvut.cz/myska/SZD/`).

Web je plně integrován do tohoto JupyterBooku a je dostupný i offline v rámci repozitáře ve složce `public_html/`.
